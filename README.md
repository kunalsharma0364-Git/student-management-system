
# Student Management System

A console-based Student Management System built with Java, JDBC, and MySQL.

## Features

- Add student records
- View all students
- Search students by ID
- Update student details
- Delete student records
- Validate user input

## Technologies

- Java
- JDBC
- MySQL
- IntelliJ IDEA

## Database Setup

1. Start your MySQL server.
2. Run the SQL script `student_management.sql` to create the database and table.
3. Configure the `DB_PASSWORD` environment variable with your MySQL password.

## How to Run

1. Open the project in IntelliJ IDEA.
2. Ensure MySQL Connector/J is added to the project.
3. Set the `DB_PASSWORD` environment variable in your Run Configuration.
4. Run `Main.java`.
